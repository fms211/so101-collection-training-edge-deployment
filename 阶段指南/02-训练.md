# 第二阶段：数据迁移与训练

采集笔记本完成各轮回放、审核和关闭后，按完整任务/版本打包：

```bash
bash 数据打包工具/启动数据打包.sh --list
bash 数据打包工具/启动数据打包.sh
```

按[打包与服务器解包手册](../数据打包工具/README_数据打包与服务器解包.md)将 tar、SHA-256 和服务器校验脚本一同转移；服务器校验解包后读回状态、动作及两路相机，再依照 [SO-101 服务器适配指南](../首次Act训练文本情况.txt/SO101_数据集判定与ACT训练服务器适配指南.md)先冒烟、再训练。训练环境、GPU、数据集和输出目录以服务器实际情况为准，不覆盖老师的 Lumos 数据。历史数据与不同动作语义的新数据应分开。

仓库另有 [ACT 启动器](../scripts/lerobot/train_act.sh)及 SmolVLA、VQ-BeT 策略脚本，依赖配置和对应环境；通过 `--help` 查看选项，`--dry-run` 先检查命令。它们不代表服务器已验证支持所有策略。
