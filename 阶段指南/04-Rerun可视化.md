# Rerun 可视化界面与轨迹回放

Rerun 是 LeRobot 用来显示机器人观测、动作和相机画面的工具。本项目的采集笔记本可以在**跟随/录制时看实时画面**，也可以在**录制结束后回放本地已保存的轨迹**。下文是根据项目代码和本机 LeRobot 0.6.1 的界面功能整理；屏幕布局会随 Rerun 版本、窗口大小和记录的数据变化，实际显示以窗口为准。

## 一、从哪里打开

先在采集笔记本图形桌面的终端激活 LeRobot 0.6.1 环境，再启动采集菜单：

```bash
cd "$HOME/so101-collection-training-edge-deployment"
bash scripts/lerobot/interactive_collection.sh
```

| 菜单 | Rerun 的作用 | 是否会让机械臂运动或记录数据 |
| --- | --- | --- |
| **2 开始跟随** | 在启动确认后，显示双相机和可用的观测/动作信息 | 真实跟随会驱动机械臂；此模式不录数据。需现场监督，终端 Ctrl+C 请求停止 |
| **3 开始／继续采集** | 录制过程的实时可视化；录制和保存状态看控制窗口与日志 | 会驱动机械臂并录制；先完成现场确认，按提示启动、结束与保存 |
| **5 回放一条数据** | 输入从 **0** 开始的 episode 编号，在本机打开已保存的轨迹 | 回放是读取数据，不发机械臂运动命令；关闭窗口后返回菜单 |

回放前先结束录制，再用菜单 4 检查数据；输入的编号是数据集内的 episode 编号，不是 `r01` 轮次号。菜单 4 的检查不等于人工审核已经通过。采集控制使用独立的控制窗口：按照提示输入 `s`、`n`、`r`、`q` 并回车；**`q` 不是急停**。操作细节见[采集助手](../SO101_交互采集助手.md)。

## 二、窗口各部分怎么看

通常可以看到下面几块；各块的位置或名称可能变化，也可能因为数据中没有对应字段而不显示：

```text
┌──────────────────── Rerun 窗口 ────────────────────┐
│ 左侧：数据/视图列表   │ 中央：顶部、腕部相机画面    │ 右侧：选中项详情 │
│                      │       关节观测/动作曲线      │                │
├───────────────────────────────────────────────────┤
│ 底部：时间轴、播放/暂停，拖动定位到某一时刻        │
└───────────────────────────────────────────────────┘
```

- **中央画面区**：`top` 是外部顶部相机，`wrist` 是腕部相机。图像用于看物体是否入镜、夹爪及目标是否被遮挡、画面是否冻结。首次检查时分别遮住两只镜头，确认画面名称与实际安装位置相符。
- **观测曲线 observation**：通常包含机器人读到的状态；对于记录数据可对应 `observation.state`。曲线随时间变化，颜色、图例和轴取决于实际数据。
- **动作曲线 action**：显示发送或记录的动作目标。项目新录制适配器保存的是限幅后**实际发送的目标动作**，这不等于机械臂一定到达了该位置。旧数据的动作语义可能不同，应分开核对。
- **底部时间轴**：在回放模式点击播放/暂停，拖动时间指针跳到某一帧或某段动作；可配合曲线和相机画面定位问题。实时模式下数据会继续进入，停止录制后是否保留取决于实际保存结果。
- **左右侧面板**：选择数据项查看详细信息或调整视图；如果面板被隐藏，可使用窗口边缘/右上角的面板按钮恢复。Rerun 的视图可调整，因此界面不一定与上图一样。

窗口结构可参考 [Rerun 官方 Viewer 介绍](https://rerun.io/docs/getting-started/configure-the-viewer)；本地图像与动作回放方式可参考 [LeRobot 数据集可视化文档](https://huggingface.co/docs/lerobot/v0.6.0/en/using_dataset_tools)。

## 三、推荐的人工检查顺序

1. 录制退出后，在菜单选 **4** 检查数据；确认有保存的 episode。
2. 选 **5**，输入 `0` 回放第一条；检查 `top` 和 `wrist` 是否为预期镜头，画面是否清晰、无遮挡、无明显冻结。
3. 播放并拖动时间轴，检查夹爪接近、接触、夹紧和放置等关键阶段；对照状态与动作曲线留意突跳、长时间不变或错位。
4. 关闭回放窗口，继续查看其他 episode；菜单 **11** 按实际观察填写 `QA.csv`，满足条件后再选 **6** 关闭轮次。
5. 如画面或曲线异常，保留数据和日志先排查，不能仅凭窗口打开或脚本退出成功认定采集合格。

可选地，在已激活环境且知道准确数据集路径及 ID 时直接调用，路径和 ID 换成实际值：

```bash
lerobot-dataset-viz \
  --repo-id 用户名/实际数据集ID \
  --root /实际路径/数据集目录 \
  --mode local \
  --episode-index 0
```

`--root` 指向直接包含 `meta/` 和 `data/` 的数据集目录；本项目使用嵌入 Parquet 的图像特征，不需要先找 MP4。`--repo-id` 必须与该数据集身份一致；命令以本地数据为输入。可通过 `lerobot-dataset-viz --help` 查看当前安装版本选项。

## 四、常见问题

- **没出现窗口**：确认使用图形桌面、已激活采集环境，执行 `command -v lerobot-dataset-viz`，再检查终端报错；纯 SSH 没有图形显示时窗口不能直接出现在笔记本桌面。
- **只有一张画面或名字反了**：检查配置中的 `TOP_CAMERA` / `WRIST_CAMERA` 及实际稳定设备路径，分别遮挡镜头确认；其他应用占用摄像头也会导致失败。
- **回放找不到数据或 episode**：确认录制已结束、菜单 4 能读回数据、数据集 ID 和目录正确，episode 编号从 0 开始；不要把残留图片目录当成完整数据集。
- **曲线没动或图像卡住**：先分清实时窗口还是已保存回放，再检查来源、时间轴、数据记录和终端日志；不能只靠单张截图认定机械臂是否正常。

Rerun 是观察工具，不能替代现场人员、急停/断电措施、物理运动确认或人工质量审核。
