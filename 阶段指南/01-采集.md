# 第一阶段：采集与审核

先阅读 [日常采集手册](../SO101%20主从臂寝室数据采集操作手册.md) 和 [交互采集助手](../SO101_交互采集助手.md)。两臂和两路相机必须连接同一台采集笔记本；现场先处理关节 3 问题并完成受监督验证。

先按[仓库首页](../README.md)在采集笔记本克隆私有仓库、配置 GitHub 访问和准备 LeRobot 环境。在仓库根目录执行，修改配置中的设备、任务和数据路径：

```bash
if [ ! -e scripts/lerobot/fms688.env ]; then
  cp scripts/lerobot/fms688.env.example scripts/lerobot/fms688.env
fi
${EDITOR:-nano} scripts/lerobot/fms688.env
source "$HOME/so101-lab/activate-lerobot.sh"
bash scripts/lerobot/interactive_collection.sh
```

配置文件只在本机保存。菜单依次完成设备检查、轮次初始化、录制、回放及 QA；确认轮次关闭后再同步或封存。脚本使用细节、键盘操作和硬件确认参见手册。训练前打包整个任务和版本，见[第二阶段](02-训练.md)。
